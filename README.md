# 血战上海滩 🎯

基于 Flutter + Flame 的本地单机街机射击游戏，支持 Android、Windows 与 Web。
一九三七年的上海，你是守在南岸街垒后的抵抗军士兵：拖动移动、火力自动倾泻，
用手雷、沙袋工事与空袭撑过五波敌军。闸北、外滩、四行仓库、苏州河四处阵地依次解锁，
也可以进入无尽模式比拼得分。

## 玩法

- 🕹️ **操作**：拖动战场任意位置移动士兵，火力自动朝正前方射击；桌面端用 WASD / 方向键移动。
- 💣 **手雷**：按钮或空格投掷，自动飞向最近敌军，12 秒冷却，优先炸装甲车与头目。
- 🧱 **工事**：按钮或 Q 在身前堆一道沙袋墙，挡住敌军子弹、被步兵挖开，站在后方减伤 40%；
  开局自带两处，最多同时 3 处，冷却 14 秒、22 秒后失效。
- ✈️ **空袭**：按钮或 E 呼叫三枚航弹覆盖敌军最密集处，落点先亮预警圈，冷却 30 秒且不伤自己。
- 🗺️ **阵地**：闸北（街巷）、外滩（江岸）、四行仓库（仓库）、苏州河（铁桥）四处，顺序解锁；
  敌军生命依次 +15% / +30% / +45%，每处都有独立的五波阵型、街景与头目。
- 🎯 **武器**：手枪常驻；弹药箱提供冲锋枪（20 秒）或霰弹枪（16 秒）。
- ❤️ **补给**：急救包回复 30 生命、钢盔提供 6 秒护盾，精英单位更容易掉落。
- 👥 **敌军**：步兵推进、枪手点射、掷弹兵抛雷、刀锋兵白刃冲锋、盾牌兵举盾硬顶正面子弹、
  装甲车三连发；手雷与空袭能绕过盾牌。
- 👑 **头目**：闸北「九七式指挥车」扇形压制，外滩「海军陆战队炮车」宽幅齐射与炮击，
  四行仓库「重型突击炮」宽幅扇面并召唤刀锋兵，苏州河「九四式装甲炮艇」四发齐射与河面炮击，
  四招一循环。
- 🏁 **阵型**：战役五波依次为前哨试探、两翼夹击、火力压制、装甲突袭、头目决战；
  苏州河为桥头遭遇、铁桥封锁、河面炮火、装甲登陆、桥心决战；
  无尽模式散兵冲击 / 交叉火力 / 炮兵掩护 / 装甲纵队轮换，每五波一个头目。
- 🏆 **计分**：连续击杀累积倍率（最高 3 倍），清波与击破头目有额外奖励，战绩保存在本机。

## 特性

- 🎨 **全程序化美术**：街道、屋顶、探照灯、街垒、阵地景物、士兵、战车与爆炸全部由 Canvas 绘制，仓库不存放图片资源。
- 🔊 **全程序化音频**：十二种提示音与 8 秒军鼓号声循环在运行时合成，SoLoud 内存音源播放，仓库不存放音频文件。
- ⚡ **固定步长战斗**：逻辑 30 / 60 / 120Hz 可选（默认 60Hz），与渲染刷新解耦；暂停、切后台立即停帧。
- 🖼️ **静态图层缓存**：路面、屋顶、探照灯、阵地景物、前景街垒、工事、装甲车与头目车体预渲染成位图；
  士兵上下半身各贴一张精灵、按 16 档步伐缓存，枪与白闪逐帧补画，粒子对象池复用。
- ♻️ **合批与画笔复用**：弹道、碎屑与余烬按颜色与透明度档位合成少量路径，一帧只留几十次 drawPath；
  爆炸火球渐变半径归一化并开局预热，八条放射碎屑合并为一条路径，稳态帧零新建 shader。
- 🌃 **四套街景**：闸北暖褐废墟、外滩冷蓝江堤、仓库砖红外墙、苏州河冷青铁桥，
  配色只换色相不换明暗，敌军与弹道在任何阵地都同样醒目。
- 🛡️ **兵种克制**：盾牌兵把正面子弹伤害削去 45%，爆炸伤害照单全收；
  刀锋兵高速贴脸，逼玩家在点射与手雷之间切换目标。
- 🧩 **数据表驱动**：兵种行为、开火参数、头目四招弹幕与士兵外观均为常量表，新增兵种只改数据不动逻辑。
- 📱 **自适应布局**：手机 / 折叠屏 / 平板 / Windows 窗口自适应；战场居中，标题与生命在上、得分在右上、
  战况与头目血条浮在战场上方或左侧、控制按钮统一在下方；窄屏自动切换紧凑 HUD。
- 🔄 **按面积选方向**：3:4 的战场在手机上竖屏更大，只有横屏确实能放大战场时才旋转全屏，退出即恢复。
- 🌓 **深色 / 浅色主题**、简体中文、Windows 优先 `Microsoft YaHei UI` 字体、Web 使用 soup_fonts 思源黑体。
- 🧾 **日志落盘**：按天写入用户目录，保留 7 天并在超过 5MB 时轮转；设置页展示路径并可打开日志目录。
- 🚫 **零联网**：没有任何网络请求，成绩与偏好全部保存在本机。

## 开发

```bash
flutter pub get
flutter analyze
flutter test
```

构建产物由 CI 生成：在 GitHub Actions / Gitea Actions 里手动运行 `build` 工作流并选定 `v*` Tag，
即按该 Tag 的版本构建 Android / Windows / Web 并创建 Release；运行 `main` 则只产出预览产物与调试站点。
音频在运行时合成、Web 字体来自 soup_fonts，仓库不存放字体与音频文件，本地无需安装 Android SDK 等大型工具链。

| --- | --- |

## 代码结构

```
lib/
├── flame/       Flame 入口、场景/战斗分层绘制、合批工具、文字缓存与静态图层注册表
├── game/        战斗模拟、实体、工事、空袭、掉落、反馈、波次编排、阵地进度与控制器
├── models/      战绩模型
├── pages/       首页、战斗页、设置页与悬浮 HUD 组件
├── providers/   偏好状态
├── services/    日志、存储、音效合成与播放
├── theme/       主题、街景/景物/单位/特效美术模块与共用画笔
└── utils/       布局几何、横竖屏判定、窗口与系统栏
```
